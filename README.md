# Ventura-browser
Ventura browser is easy and quiet browser on Phyton 

**Ventura Browser** is a lightweight, fast, and quiet web browser built with Python and PyQt6, designed for comfortable browsing without heavy CPU load or loud fan noise.

## Features
* **Quiet Performance:** No heavy background processes, telemetry, or bloated extensions.
* **Tab Support:** Easily open, switch between, and close multiple tabs.
* **Smart Address Bar:** Supports direct URLs and instant Google search queries.
* **Cross-Platform:** Works seamlessly on both macOS and Windows.

## How to Run from Source

1. Clone the repository or download the `browser.py` file.
2. Install the required dependencies:
   ```bash
   pip install PyQt6 PyQt6-WebEngine
   ```
3. Run the browser:
   ```bash
   python3 browser.py
   ```
